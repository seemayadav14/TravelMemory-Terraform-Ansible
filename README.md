# TravelMemory - Terraform and Ansible Deployment

## Project Overview
This project demonstrates infrastructure provisioning using Terraform and configuration management using Ansible to deploy the TravelMemory MERN application on AWS.

## Technologies Used
- AWS
- Terraform
- Ansible
- Ubuntu Linux
- MongoDB
- Node.js
- React
- Git and GitHub

## Project Structure
- terraform/ - AWS infrastructure configuration
- ansible/ - Database and web server playbooks
- screenshots/ - Assignment execution evidence
- README.md - Project documentation

## Terraform
Terraform files define AWS networking, security groups, IAM resources, and EC2 infrastructure.

## Ansible
Ansible playbooks configure the database and web server.
